## Описание задачи

**Задача:** Бинарная классификация (прогнозирование вероятности ухода клиента). Цель проекта — удержание абонентов путем выявления клиентов из зоны риска для предоставления им персональных скидок и оптимизации маркетингового бюджета.

**Датасет:** Содержит финансовые показатели, статистику звонков и заявленный уровень удовлетворенности абонентов. Объем: 20 000 записей.

**Целевая метрика:** 
* Основная ML-метрика: **ROC-AUC** (оценивает качество ранжирования вероятностей).
* Вспомогательная бизнес-метрика: **F1-score** (использовалась для оптимизации порога отсечения).

## Запуск

Проект поддерживает два способа развертывания: локальный запуск через виртуальное окружение и запуск в изолированном контейнере Docker.

**Способ 1: Локальный запуск**
1. Клонировать репозиторий
git clone <url-вашего-репозитория>
cd <repo-name>

2. Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate для Linux/macOS или
.venv\Scripts\activate для Windows

3. Установить зависимости
pip install -r requirements.txt

4. Запустить FastAPI сервер
uvicorn src.api:app --reload

После запуска перейдите в браузере по адресу http://127.0.0.1:8000/docs для доступа к Swagger UI.

**Способ 2: Запуск через Docker**

Убедитесь, что у вас установлен Docker Desktop. В корне проекта выполните:
docker-compose up --build

Сервер будет доступен по адресу http://localhost:8000/docs.

## Результаты

В ходе экспериментов было протестировано 7 различных алгоритмов машинного обучения. Финальная модель (HistGradientBoosting) прошла глубокий тюнинг гиперпараметров и оптимизацию порога классификации.

| Модель | ROC-AUC (Test) | F1-Score (Test) | Примечание |
|---|---|---|---|
| Baseline (Logistic Regression) | 0.6987 | 0.6313 | Сырье признаки (без Feature Engineering). Порог 0.5. |
| HistGradientBoosting | 0.7710 | 0.7417 | **Финальная модель.** Использован Feature Engineering. Смещен порог вероятности отсечения (\(Threshold = 0.4059\)). |
